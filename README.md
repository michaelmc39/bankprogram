A simple command-line banking app I made in python. I made this project to practise Python fundamentals like functions, loops, conditional statements, user inputs and working with variables.

The app lets users check their balance, deposit money, withdraw, prevent withdrawls that exceed balance, reject negative deposit and withdrawal amounts, exit the program through the menu.
When the program starts, the user's balance is set to £0.00.

The user is presented with a menu:

Banking Program
1. Show Balance
2. Deposit
3. Withdraw
4. Exit

The program continues running until the user selects Exit.
Show Balance
Displays the user's current balance formatted to two decimal places.
Deposit
Allows the user to enter an amount to add to their balance. Negative deposits are rejected.
Withdraw
Allows the user to withdraw money from their balance. The program checks that the user has sufficient funds and prevents negative withdrawal amounts.

From doing this project, i learnt functions, parameters and return values, while loops, if, elif, and else statements, user input, floating point numbers, f-strings, basic input validation, the if name =="__main__" pattern.
